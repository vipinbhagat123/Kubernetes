# Kubernetes

A beginner-friendly repository for learning Kubernetes concepts, commands, and hands-on examples.

## 📚 Topics Covered
- Kubernetes Architecture
- Pods
- ReplicaSets
- Deployments
- Services
- Namespaces
- ConfigMaps & Secrets
- Volumes & Persistent Volumes
- StatefulSets
- DaemonSets
- Jobs & CronJobs
- Ingress
- Helm Basics

## 🛠 Prerequisites
- Docker
- kubectl
- Minikube or Kind
- Basic knowledge of containers

## 🚀 Getting Started
1. Install Docker.
2. Install kubectl.
3. Create a local Kubernetes cluster using Minikube or Kind.
4. Apply YAML manifests using:

```bash
kubectl apply -f <file>.yaml
```
